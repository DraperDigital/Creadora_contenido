# Biblioteca de fotos (b-roll)

Coloca aqui las fotos del cliente (`.jpg`, `.jpeg`, `.png`, `.webp`).

Se usan para los formatos con foto: carrusel sobre fotos, frases sobre foto,
video sin cara, y el efecto de texto detras de la persona. Si la carpeta esta
vacia, esos formatos simplemente se omiten (no fallan).
