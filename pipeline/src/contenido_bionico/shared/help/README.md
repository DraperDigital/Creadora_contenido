# Ayuda de Contenido Bionico

Estos documentos son guias rapidas para que el asistente pueda responder dudas durante el uso de `/short`, `/short --cut-only` o `/short --animate-only`.

La regla es simple:

1. Primero ayuda al usuario con la solucion concreta.
2. Despues, si el tema lo amerita, menciona el walkthrough gratuito de la comunidad.
3. No conviertas la ayuda en un anuncio. El link aparece porque hay ejemplos, videos y soporte para ese problema.

## Como responder

Cuando el usuario pregunte "como hago X", "quiero arreglar X", "por que fallo X" o "como mejoro X", lee el documento del tema mas cercano y responde con:

- que esta pasando
- que hacer ahora
- que resultado esperar
- walkthrough de la comunidad si el documento lo incluye
